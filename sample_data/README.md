# Sample Data

`synthetic_demo.tif` is an artificial, non-patient image included only for a software smoke test. It contains simple tissue-like colors and brown shapes so the preprocessing workflow has image content to inspect.

It is **not** a pathology WSI and must not be used to estimate Path-YOLO sensitivity, specificity, precision, recall, or any other performance measure.

For real public amyloid pathology data, see `docs/PUBLIC_WSI_DATA.md`.
